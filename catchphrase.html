📜 Catchphrase Game Rules

🧩 The Objective

A hidden picture or phrase is covered by a grid of numbered tiles. Players try to guess what the image represents as tiles are removed.

🎮 Gameplay Loop

Click tiles to reveal the question behind them. If a player buzzes in, start the timer. If they guess correctly, click ✔️ Correct to award Tile Points and remove that tile to reveal a piece of the board!

🎯 Guessing the Board

At any time, a player can attempt to guess the main hidden picture. The host clicks "Guess the Board". If they are right, they get the massive Board Points bonus and the whole image is automatically revealed!

↩️ Undo & Correction

Did you accidentally click the wrong tile or give the wrong person points? The Undo Last Action button acts like a time machine—it will systematically reverse every single click and score change you make, in the exact order you made them.

💻 Technical Guide & Media

📂 Supported Media Formats

✨ Drag & Drop + Clipboard Paste: You can drag images, audio, or web URLs straight onto any question box. Taking screenshots with Win+Shift+S or Cmd+Shift+4 and pressing Ctrl+V will paste image data automatically!

🖼️ Images: .jpg, .jpeg, .png, .gif, .webp.

🎬 Videos & Backgrounds: .mp4, .webm, and YouTube Links.

☁️ Cloud Storage Links

Standard "Share" links point to a web viewer page, which won't load. You must use public direct links:

  • Google Drive: Set to "Anyone with the link can view". Take your file ID and use this format: https://drive.google.com/uc?export=download&id=FILE_ID
  • OneDrive: Open the video, click the three dots (`...`), select Embed, and copy the src="..." URL string.

🌐 Hosting & Local Files

Streamers & Hosts: Use the "Host Cheat Sheet" button to open a separate popup window containing all answers for the current round. You can drag this to a second monitor so viewers won't see it on your main screen share!
